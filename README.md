# אוויר בהדרים – תחזית עשן והתראות

תחזית מראש והתראות בזמן אמת על עשן משריפות פסולת בשכונת הדרים, שוהם.

## מה רץ ומתי
| מה | מתי | קובץ |
|---|---|---|
| בדיקת הניידת והתראה כשהעשן מגיע או עוזב | כל 15 דקות | `.github/workflows/live.yml` |
| תחזית ללילה הקרוב ולמחרת, והודעה יומית | 05:00 ו-15:00 | `.github/workflows/forecast.yml` |
| אימון מחדש על כל הנתונים שהצטברו | כל יום ראשון | אותו קובץ |

## מקורות נתונים
- **ניידת 5 של המשרד להגנת הסביבה** (תחנה 339, האתרוג 60): בנזן, טולואן, PM2.5 ותחמוצות חנקן, דרך הספרייה הפתוחה `air-sviva-api`.
- **Open-Meteo**: היסטוריה ותחזית של רוח, שכבת ערבוב, גשם ולחות.

## ממצאי הניתוח הראשוני (דצמבר 2025 – נובמבר 2026)
- הבנזן עולה מ-20:00, עם שיא סביב 03:00.
- כ-35% מהלילות היו "רעים" (3 שעות או יותר עם בנזן מעל 3).
- העשן מגיע כמעט רק ברוח מזרחית או דרום-מזרחית, חלשה, ושכבת ערבוב מתחת ל-150 מטר.
- מודל שמבוסס רק על מזג האוויר זיהה 72% מהלילות הרעים, ו-56% מההתראות שלו היו נכונות. כדי לבדוק אותו הוגן, בכל פעם אומן בלי החודש שנבדק.

## הפעלת התראות
ב-Settings ← Secrets ← Actions:
- **טלגרם** (חינם, הכי פשוט): `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`
- **וואטסאפ** (Cloud API הרשמי): `WA_TOKEN`, `WA_PHONE_ID`, `WA_RECIPIENTS`. דורש תבנית הודעה מאושרת בשם `smoke_alert`.

## האתר
Settings ← Pages ← Source: `main` / `docs`.

## דיווחי תושבים ("מריחים עשן?")
1. ליצור Google Sheet חדש, ואז Extensions ← Apps Script ← להדביק את `reports/Code.gs`.
2. Deploy ← New deployment ← Web app ← Execute as: Me ← Who has access: **Anyone**.
3. את כתובת ה-`/exec` לשים גם ב-`REPORTS_URL` שב-`docs/index.html` וגם ב-secret `REPORTS_URL`.
